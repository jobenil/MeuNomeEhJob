## 4. Dúvida técnica: como suprimir avisos (warnings) na renderização

**Pedido:** O usuário perguntou quais parâmetros usar no `.qmd` para que, ao renderizar, apareça apenas o gráfico, sem avisos.

**Resposta dada:**

- **Por chunk** (já usado nos blocos `{r}` do post, funciona igual em `{python}`):
  ```text
  {python warning=FALSE, message=FALSE}
  ```
  ou, na sintaxe nova (pipe), dentro do chunk:
  ```text
  #| warning: false
  #| message: false
  ```
- **Para o post inteiro**, evitando repetir em cada bloco — adicionar no cabeçalho YAML:
  ```yaml
  execute:
    warning: false
    message: false
  ```

Foi oferecido aplicar a opção de documento inteiro no arquivo, ficando pendente de confirmação do usuário.
